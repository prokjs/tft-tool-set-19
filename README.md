# prokjs's Set 19 TFT tool · v0.7.5

**Developed by prokjs.**

Offline Windows TFT Set 19 champion-combination and trait-relationship explorer. **Unapproved experimental prototype.** Manual in-game unlock confirmations and board transitions are not cleared by Riot; current-state recommendations carry TFT policy risk. It does not predict or guarantee match outcomes.

Build a hypothetical five- or six-champion Collab pool directly in the main portrait grid. While the pool is **unlocked**, click a portrait to add/remove it; conflicting candidates disappear, selected picks stay removable, and Sona is automatic. Click **Lock Collab pool** to restore the full roster and enable team-building. **Unlock Collab pool** returns to filtered picking without losing your picks or team settings. **Reset** clears pool picks, team locks, exclusions and star overrides.

Once the pool is locked, click portraits to select, Ctrl-click for multiple selections, or Shift-click for a range. **Team lock**, Exclude, and **Planned stars** affect the selected units—not the Collab pool. Picker and Collab-strip portraits always show ★ unless the user explicitly chooses another rank. Guide/Final portraits separately show their phase's planned progression; these targets are not owned copies. K/DA counts only fielded phase ranks, not the picker or a future rank. Manual overrides remain authoritative.

Cost and planned star markers sit directly on champion portraits. Item builds use bundled item-artwork icons; tank, AD, AP and flex assignments use role icons. Hover or focus for names and full metadata. Quest padlocks, Collab/team-lock/exclusion flags and weighted-slot indicators remain distinct.

Precomputed item handoffs are matched to the final carry's archetype before generic damage-type holders: attack-speed users, assassins, fighters/bruisers, or ability casters. Sourced roles and item trios identify the archetype; Rageblade/Kraken builds also identify attack-speed casters or specialists such as Xayah/Jhin. An assassin can use a fighter as a related melee fallback before a generic AD holder. Existing late-game eligibility still applies, then planned strength and continuity break ties. An under-upgraded final target is not preferred by name alone. Hover an item route for its archetype and fallback status; actual transfers still require selling the outgoing holder or an item remover when retained.

The theorycraft rail fills the available desktop height. Champion portraits pack edge-to-edge at the largest square size that fits the visible roster, with a 32px minimum and scrolling if necessary. Hover and keyboard focus never move or resize portraits. Search dims nonmatches in place without rebuilding or reordering tiles. Cost, star, quest-lock and selection badges remain visible. Small windows use a natural-flow 40px grid.

The desktop workspace uses compact trait cards, lineup portraits and an enlarged estimated board. **Show all options** controls alternative portraits without changing selections or pins. Turning it off hides the alternatives, enlarges the selected portrait within each hex and overlays its assigned items inside the hex. Champion clicks/details show that champion's own recommended BiS trio with its source; role-based suggestions are identified rather than claimed as verified BiS. Recommended items are separate from collected/assigned inventory and never create equipment.

Selecting a comp closes the drawer and opens **Final** first. **Final** follows the level tabs and shares their board area. Level tabs retain their Arrival and upgrade phases. The search query clears after a successful initial pool pick; locked-team selection keeps its query.

**Completed unlocks** has its own right-edge tab and scrollable drawer, not a blocking modal. Click or drag either edge tab; opening one closes the other. Close with × or Escape. Match-level selection, completion timestamps, reset and requirement details remain available. On enlarged hex portraits, stars sit above the items with no star background.

**Hold for Final** sits beneath the active traits, to the left of the hex board, with larger portraits and a visible buy-and-keep reminder. It stays visible on Final and every leveling phase for all 1- and 2-cost champions in the selected end comp, including units not currently fielded, and follows branch changes and Reset comp. Buy them when available and keep a copy rather than accidentally skipping or selling them during temporary swaps. If a planned item transfer requires selling a holder, reserve another copy or use an item remover; unlock requirements still apply. Champion tooltips and copied plans retain this reminder.

The **◇ pre-game scenario** control assumes an early champion, availability level and planned star rank, then rebuilds the selected comp's leveling path. It is a static what-if tool, not an “I own this” input or live recommendation mode. Assumptions can bypass conservative shop-planning timing, never published unlock levels or prerequisite checks. Applying or clearing them resets temporary-unit choices while keeping the final champion roster fixed; clear removes scenario-only timing/rank assumptions. Source conditions and planned-copy requirements still apply.

Level and upgrade-phase selection share one row, without previous/next buttons. Requirement descriptions use trait/champion icons and emphasize numeric values; full wording remains accessible on hover and in details. The language-coverage banner has a close button and stays dismissed for the current language during the session.

Changing an earlier-level temporary champion while later manual choices exist opens a confirmation listing downstream choices to reset. **Change and rebuild later levels** applies the branch and clears those later selections; Cancel leaves everything unchanged. Earlier boards, fielded Final-core units, confirmed unlocks and collected inventory remain intact.

Clicking the already selected small portrait only previews its own item suggestions; it does not pin the champion. Choosing a different temporary option adapts the selected team's future Final composition to that branch, retaining already-fielded required core units. The guide still reaches that updated Final through legal prerequisites and explicit purchases/upgrades. Fielded Final members have no swap options. Recommended choices are distinct from selected choices and show which Final traits or unlock targets they help prepare—not proof of task completion or measured win rates.

**Reset comp**, beside **Collected items / starting board**, restores only the selected team's original search recommendation and opens Final. It clears that comp's temporary choices, early-availability edits, damage alternatives and cached cap-out; collected inventory, confirmed starting board/ranks, current match level, unlock confirmations and other suggested teams are preserved.

**NO AD items** and **NO AP items** sit beside the displayed board, not in the search settings. They generate a compatible carry/item-plan alternative only for the selected comp and viewed level/phase; the other suggested teams stay unchanged. Level changes preserve the earlier path and normal Final goal; a Final-view change keeps the unaffected core. Clearing a switch restores that view's original plan. Locks, shop gates and unlock requirements still apply. Missing offensive items are never invented, and actual collected inventory remains authoritative.

Desktop windows 680–800 pixels tall use two trait columns to fit localized trait cards without extending the page.

The layout spends available width and height on the board instead of fixed caps and blank margins. Unlock preparation occupies a compact side panel beside the board; extra explanations, assumptions, source notes and legal notices open through accessible ⓘ controls. Missing requirement champions are greyed against the displayed level/phase, not an inferred owned roster. Experimental manual unlock tracking affects eligibility and paths, but does not read the game client, infer quest completion, or establish owned units/items/gold.

The **estimated 4×7 player-half hex board** uses bundled, sourced attack ranges and combat roles—not measured positioning win rates. Tanks form a connected group across the front-middle, biased toward the right-side carry group, with no gaps between them. The main tank starts one hex off center; outer edge hexes are only used after the five interior hexes are filled. A true solo Amumu instead starts dead center with adjacent friendly hexes reserved empty. Melee and two-range units prefer protected second-row hexes; longer-range units cluster toward the right backline, while Teemo reserves the back-center hex. Baron uses one physical marker despite costing two team slots. Hover for placement reasons and sources. This is a starting arrangement, not enemy scouting, combat simulation, or optimal-positioning data. Display ordering does not alter native team-code champion order.

Champion-card rows are measured from their current fonts and wrapped text, with padding reserved inside every colored border. Trait bars similarly expand to fit both text lines rather than drawing breakpoint numbers through their lower edge.

Each card's **Traits NN%** means **trait-tier activation**, not DPS, champion efficiency, buff magnitude, or a reason to treat a Tank as a carry. It averages the ordinal reached tier divided by the number of tiers for that champion's applicable non-unique traits, including current Collab membership and Sona's featured band. Unique traits are explained but excluded; no applicable tiered traits displays **Traits n/a**. Hover or click for the individual counts, reached breakpoints, and definition note. Item-holder suggestions remain separate.

Trait hovers appear immediately and dismiss as soon as the pointer leaves the trait box, including when moving toward the popup. They show the sourced effect and matching champion catalogue from the bundled offline reference. Collab membership and Sona's featured band use the current comp context.

Hover text separates the effect and breakpoints, highlights the current tier, and emphasizes important values and stats. Long effects can be scrolled while the cursor stays on the trait box; moving onto the popup itself closes it.

Unlockable champions have a corner padlock marking their sourced quest. The manual **Unlocks** checklist separately records completion at an explicitly selected match level; checking a task is not a claim that the champion is purchased or fielded. Confirmations affect current/future eligible paths without retroactively unlocking earlier levels. Published minimum levels still apply; unchecked tasks remain required. Clear confirmations for a new game. Portrait tooltips, requirement details and exports retain source conditions and completion metadata.

**Copy TFT code** copies a native team-planner code for the selected lineup using the public version-02 Set 19 format: ten three-hex-digit ID slots (empty slots use `000`) and the `TFTSet19` suffix. Codes support at most ten distinct champion entries; teams are never truncated. Baron Nashor encodes as one champion entry despite occupying two board slots. Codes carry the lineup order, not stars, items, positions, Collab selection, or unlock state. **Copy plan** separately copies readable planned stars, unlock conditions, strategy notes, and level buildups; **Save JSON** exports the full result data.

The bundled mapping contains 89 supported champion IDs, including the two distinct Akalis. Five champions are deliberately unsupported: Graves, Mordekaiser, and Nasus share one published ID; Kennen and Kobuko have unresolved cross-source ID conflicts. Selecting any of these produces a clear error instead of a fabricated code. Provenance and conflicting source values are retained with the mapping. Published format/source evidence is not a claim of testing every roster in the live game client.

## Level-by-level buildups

The default final level is **10**. Selecting a comp opens the embedded main-screen guide and Final view. Explicit leveling branches can adapt that team's future Final; arrivals, prerequisite setups and conditional upgrades remain separate phases. Copies and JSON exports include the selected branch and its resulting end goal.

Both interfaces show estimated boards for arrivals, upgrades, unlock setups and playable alternatives. Only nonfinal temporary slots offer champion alternatives; ⓘ opens additional validated options. Selecting an alternative rebuilds that team's future path and Final while retaining already-fielded Final core and preserving the preceding history. Shop gates, exclusions, weighted slots, normal/reroll conventions and prerequisite helpers still apply. **Reset comp** returns to the original search recommendation.

Each level opens on its **Arrival** board, preserving most of the previous lineup rather than recommending a fresh team every level. Primary steps normally remove at most one champion below level 8 and two at level 8+. At the final level, Arrival can still contain temporary units: the selected comp is the **ideal end goal**, not an instant full-team replacement. A compact phase selector shows the actual gradual same-level upgrades, ending at that exact goal. Hold Arrival until the needed champions are found; buy incoming units before selling their replacements, and verify unlocks before fielding them. Phases do not claim owned units, available gold, or completed quests. Weighted two-slot Baron transitions can require a larger exchange, which the plan explains explicitly.

Each level and upgrade phase prominently lists exact **Replace outgoing → incoming** exchanges before its board. **Same-role** exchanges prefer compatible Tank, AD, AP, or AD/AP-flex profiles; **roster-only** exchanges are lineup changes, not item-role recommendations. Grouped exchanges account for Baron's two slots, while open-slot additions are shown separately. The fallback board is an independent alternative, not another phase.

The main comp and guide boards show **Tank / AD / AP / flex item-holder options**, with matching labels on holder cards. These use sourced champion combat roles rather than trait guesses; Tank takes precedence over damage type. Missing eligible roles show **no suitable holder**. Holder choices consider planned stars as well as rarity, so a real upgraded early carry is not automatically displaced by a one-star premium utility unit. Yone is explicitly **AD/AP flex**: choose one build for the items available, never two simultaneous item sets. These categories are alternatives, not a claim that you own three full sets of items.

When flex Yone is available without a dedicated AD or AP holder, those categories read **no dedicated holder**, not an assertion that Yone cannot use their items. His **AD/AP FLEX** card label denotes one alternative build, not two allocations.

Item handoffs are conditional instructions, not inventory simulation. Selling an outgoing holder releases its items; if the old holder remains fielded, the guide explicitly requires an **item remover or a later sale**. AD/AP-flex handoffs depend on the build actually chosen. No item ownership, removable-item availability, or completed quest is assumed.

Quest-dependent boards are conditional, not proof that unlocks are complete. The planner also shows independent no-unlock alternatives where feasible, or an explicit reason when no exact-slot board exists—never invented fillers. Temporary Annie, Ziggs, Xayah, or other relevant helpers can intentionally prepare a later target's unlock. **Unlock preparation** names that future target and its complete task; fielding a one-star helper does not satisfy a two-star, item, streak, or progress requirement. For example, preparing Evelynn with three K/DA champions means **three different champions**, not three K/DA star levels; follow the full sourced task and confirm the unlock after the required combat before making the handoff. Keep helpers until the required unlock is actually earned, then follow the conditional handoff.

Preparation is enforced in the **actual primary phase sequence**, not merely offered as an independent sideboard. For Akali K/DA, a prior fielded setup must reach 12 K/DA stars **without Akali counting toward her own unlock**, followed by an explicit conditional unlock check before buying her. Helper acquisitions, star upgrades and later swaps are separate ordered actions. Known impossible prerequisites are rejected rather than bypassed. Checks remain instructions to complete and verify the sourced task, not simulated quest progress.

Unlock setups must form a followable primary path, not a brief sideboard followed by reversing the whole team. Major preparation pivots favor level 8 (the usual stage-4-2 planning point), and useful helpers remain until the task's conditional check/acquisition. Smeech needs eight active non-unique traits without counting himself: prepare that actual board around level 8 and respect his published level-9 unlock gate. Any unavoidable large overhaul has a visible fast-micro warning and exact buy/add/remove sequence; the tool does not know actual gold or bench space.

**Unlock preparation is an actual lineup, not just a repeated quest description.** Setup boards appear before arrivals at every level, with explicit unavailable/manual states. Thresh's path shows active Classical from the earliest feasible setup and explains holding it across combats; it never infers accumulated Captivation from leveling. Smeech setups must actually reach eight active non-unique traits without Smeech. Vladimir setup positioning places exactly one unit in the front two rows. Items, required upgrades, progress, economy, streaks, ensemble and conditional helper unlocks must still be completed and verified manually.

**Final-carry item plans** travel with the guide: each eligible temporary holder shows the final carry's three planned items and destination. Missing suitable holders leave the set unassigned. Published champion trios/recommended lists are distinguished visibly from explicit role-based suggestions where PBE builds are unavailable; none is guaranteed best-in-slot. Source, selection method and notes are bundled in `data/item_builds.json`; refresh with `python tools/update_item_builds.py`. Item ownership is never assumed; transferring items still requires selling the holder or using an actual remover.


End-board locks do not force late-game units onto early boards. Units enter at ★; retained ranks never silently fall. Normal planned ★★ targets are: 1-cost keepers, pins and planned main item holders at level 4, other 1-costs at level 5; 2-costs at level 6; 3-costs at level 7; 4-costs at level 8; 5-costs at level 10. Seven-costs stay ★ unless explicitly changed. A normal goal not aiming for Sona, a majority-1/2-cost goal, or an explicit cheap three-star commitment included in that goal identifies a reroll plan: persistent 1/2/3-cost targets plan ★★★ at levels 5/6/7 respectively, especially K/DA and permanent holders. An unchecked Sona task does not turn a Collab plan into reroll; Cap-out is not automatically reroll. Every increase is an explicit planned-copy action, not guaranteed purchases or free stars; temporary one-combat helpers do not automatically receive reroll investment. Source unlock tasks cannot invent automatic four-star helpers or bypass these timing assumptions.

Default acquisition planning remains separate from upgrades: 1-costs from level 1, 2-costs from level 3, 3-costs from level 4, 4-costs from level 7, and 5-costs from level 9. Explicit pre-game early-availability assumptions may override conservative access estimates, never source unlock minima/tasks. Confirmed unlocks use actual nonzero ordinary-shop availability where applicable; quest-only units never acquire invented ordinary shop odds. Level 11 requires a level-cap extension; normal capacity is one slot per level, with Baron occupying two.

Default recommendations avoid unrelated long unlock chains. Unlockable **Hyperpop** units require an actual native-Hyperpop Collab pick or Hyperpop as Sona's featured band; ordinary Ziggs remains allowed. Other long-chain targets require relevant Collab support: Gu Feng for unlockable Gu Feng units, Heartsteel for Aphelios, K/DA for Akali K/DA, True Damage for Akali True Damage, Ionic Spark for Gwen, Pentakill for Mordekaiser, and Beach Pop for Taliyah. Baron requires Baron or Malzahar Collab support; Rakan's streak path requires Rakan Collab support. Jazz's single Smeech unlock can still be prepared through a real Jazz bridge, and simple conditional unlocks such as Annie → Tibbers are not blanket-banned. **Team lock** is an explicit manual opt-in to otherwise restricted end-goal chains and retains a planning warning; necessary dependency-band helpers may appear in that goal's guide without licensing unrelated chain targets in the final search. Every allowed quest remains conditional.

Shop timing references the [TFT Flow Set 19 shop table, patch 19.1](https://tftflow.com/tables/set19/shop-odds-pool-size-xp-table), with the conservative planning minima above. These are heuristic transitions, not round-by-round economy or shop simulations.

## Rankings

- **High value** (default): rewards higher-cost units alongside synergy depth, conditional Jazz value, and frontline balance. Base cost contributes 30 points per gold; cost is a heuristic, not measured strength.
- **Balanced**: uses the same deep-trait and lineup-context preferences without the base-cost bonus.
- **Most active traits**: remains breadth-first, favoring activations rather than the late-game strategy preferences below.

Roster gold is the sum of base champion costs, not the gold needed for star upgrades. High value is a rarity/cost heuristic, not measured combat strength. Locks, exclusions, Collab minimums, and team-slot limits apply in every mode.

Balanced and High value favor deeper breakpoints, not just many shallow splashes. Jazz adds value only for actually active fielded synergies. At level 10+, the best qualifying upgraded Tank contributes the frontline-anchor preference; a three-star cheap Tank can remain the anchor while other units follow their normal two-star schedule. Explicit requested ranks remain authoritative.

At level 10+, Balanced and High value add one capped preference for a fielded late-game carry, rather than penalizing every cheap synergy unit. Final carry/item targets favor 3-cost-and-higher damage units over 1–2-cost units below three stars. Three-star cheap carries remain valid; a fielded 1–3-cost three-star-or-higher target identifies a reroll plan and permits its cheap carries. Unfielded star targets do not trigger this exception. Earlier boards and temporary item handoffs remain available. These are planning preferences, not measured combat-strength claims.

**Cap-out** is an item-aware post-cashout alternative after Final, not a generic legendary roster. Review the level-10 starting roster/ranks and enter actual collected item copies with their current holder or bench location. A separate, explicit source-plan what-if may use the original comp's suggested sets; suggestions are never silently marked collected. Item instances are finite and unique: each copy appears once, each champion has at most three occupied slots, and unused equipment remains on the bench. Selling a holder releases those exact items; retained holders keep their items unless a real transfer condition is satisfied. Opening Cap-out does not establish a cashout, purchase, upgrade, remover or crafted item.

Selection considers item compatibility before choosing the roster. Shojin/Jeweled Gauntlet/Deathcap support a caster core rather than spawning fighter sets. Upgraded incumbent carries/frontline and useful carry-support synergies are retained unless a compatible replacement justifies the disruption; new legendary hits are conservatively valued at one star unless an available upgraded copy is explicitly reported. Normal guide star targets remain planned copy-acquisition steps, not already-owned replacements. Existing copies and shop unlocks remain distinct; published gates and hard locks/exclusions still constrain new acquisitions. Cap-out is a heuristic, not a combat-strength or win-rate guarantee.

Released and bench items use compatibility first, then acquisition-rank/cost strength to choose between equally compatible recipients; only remaining ties use occupied slots and canonical name order. Future planned upgrades are not treated as available copies, and a stronger unit cannot take items from a retained holder without a legal release.

Planned Final-versus-cap-out comparisons share the same conditional source-unlock assumptions: an unchecked live task alone does not evict a quest champion already assumed by the planned Final. These assumptions do not confirm unlocks, ownership, purchases or cashout, and do not unlock unrelated new quest champions. Actual inventory/snapshot mode remains separate. Replacement details distinguish hard eligibility exclusions from heuristic changes. Equipped main holders are selected by their phase's rank/strength and actual compatible item fit, not alphabetical order; physical item custody remains unchanged.

The local item inventory catalog records Set 19 names, kinds, tags, descriptions and provenance from the IES game-data export. The existing bundled artwork is used where available; other catalogued items retain their actual names and accessible text labels. Inventory does not automatically craft components or consume tools. Extra or unmodelled effects are not invented to justify an allocation.

For these two modes, shallow Gu Feng, True Damage without a qualifying fielded carry, and shallow late-game Hyperpop without an upgraded member receive value discounts, not altered trait counts. Fast-10 plans apply a heuristic penalty to 3-star cheap reroll targets and a smaller penalty to exactly 2-star Qiyana; this is not an economy simulation or proof the upgrade is hit. Senna receives a current-patch preference penalty, not a ban or a measured win-rate claim. Result notes and copied plans record relevant assumptions.

## Language and tutorial

**Language settings** is at the top right. All 28 locales listed by Riot are selectable, with offline community-assisted UI catalogs and official localized League champion names where available. Set 19 PBE trait translations can be incomplete; source-locale aliases, community fallback and provenance are recorded rather than represented as complete official translations. Canonical keys, calculations, roles, artwork lookup and native TFT codes do not change with the display language. The selected language is saved per user; Arabic display uses the Windows ICU service with MIT-licensed Arabic joining.

**How to use**, beside the language settings, contains exactly four steps:

1. Choose a language.
2. Select or reset the Collab pool.
3. Find and select teams.
4. Navigate the embedded leveling guide, review unlock setups and choose temporary champions.

## Run and build

- Prerequisites: Node.js 20+, Rust stable, Windows MSVC C++ Build Tools and WebView2 Runtime.
- One-time setup: `npm ci`, `rustup target add wasm32-unknown-unknown`, and `cargo install wasm-bindgen-cli --version 0.2.130 --locked`.
- Rust engine tests: `cargo test -p tft-core`.
- Browser build: `npm run build:web`; browser preview: `npm run preview`.
- Desktop development: `npm run tauri:dev`; release executable: `./build.ps1` in PowerShell.
- `build.ps1` builds Rust/WASM, collects Cargo notices, builds Tauri and copies the Windows executable to `dist/rust-0.7.5/`. Python is used only by build-time notice/catalog collection and existing data-maintenance tools, never by the shipped app.
- Preserve `THIRD_PARTY_NOTICES.txt` and `LEGAL.md` with distributions. `Cargo.lock` and `package-lock.json` pin dependencies; the generated `frontend-dist/`, `web/pkg/` and `target/` are not source.

Rankings use approximate synergy heuristics, not measured win rates. Bundled data is a pre-release snapshot.
